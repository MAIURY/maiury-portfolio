# Maiury Fernandes Portfolio

Single-page portfolio built with React + Vite and Tailwind via CDN.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:5173

## Conteudo

Todos os textos ficam em [src/content.js](src/content.js). Atualize esse arquivo para mudar textos, links e imagens.

## Deploy no GitHub Pages

```bash
npm install
npm run deploy
```

No GitHub, configure o Pages para usar a branch `gh-pages`.
